# 新物图标系统 · v2

目标：读者能识别产品类别，知道每个操作会去哪里。保留网站纸白、石墨黑与橙色的视觉方向。

## 第二版：有体积感的分类物件

用户提供 Apple 设计大奖页面后，新增 5 枚 160 × 160 原创 SVG 分类插画。借鉴 Tide Guide 的物件层次和 Moonlitt 的简洁立体主体，不复制现有 App 图标。统一左上方光源、圆角底板、奶油白/石墨机身、新物橙细节与柔和投影。

- 源数据：`src/data/category-art.ts`；输出：`/category-icons/<name>.svg`。
- `CategoryIcon.astro` 在首页与产品库复用，作为配有中文标签的装饰图片。
- 桌面分类图 56px，手机 39–44px。
- 分类依然通过文字、轮廓、下划线和边框标明类别及选中状态；不只靠颜色。
- 16 枚基础线条图标保留，搜索/菜单等功能继续使用简洁线条。
- 本轮没有改动品牌标志，也没有将分类插画冒充具体产品照片。

## 本次参考

- Apple 设计大奖：https://developer.apple.com/cn/design/awards/ 。用户指定的视觉参考，实际查看 2026 年获奖 App 图标。

- Apple 中国商店：https://www.apple.com.cn/store 。借鉴产品类别有明确文字名称的组织方式。
- Nothing：https://nothing.tech/ 。借鉴统一的品牌语言与 Discover / Learn more 等文字行动提示。
- Nielsen Norman Group：https://www.nngroup.com/articles/icon-usability/ 。参考多数图标需要文字标签降低歧义的原则。

只借鉴使用原则；不复制其图标路径、字标、点阵或其他品牌识别资产。

## 图形规则

- 图标在 `src/data/icons.ts` 中全新绘制，共 16 枚。
- 24 × 24 画布，1.65 单位描边，圆头、圆角；沿用硬件机身、按键、镜片的具体轮廓。
- 橙色只用于少量辅助细节，不作为区别类别或状态的唯一方式。
- 按钮深色状态时，橙色细节随文字变为浅色，保持可辨识度。
- 品牌标记采用打开的圆角框、框外圆点和加号；它是品牌识别，不承担按钮功能。
- 功能图标按控件大小使用，始终保留必要的文字说明。

## 使用规则

1. 站内入口使用“查看产品”“浏览专题”“了解合作方式”等文字，不显示外部窗口图标。
2. 外部窗口图标只在真正离开本站的链接中使用，链接注明目标并设置 `target="_blank"` 与 `rel="noopener noreferrer"`。
3. 下载图标只表示保存文件，保存草稿图标只表示本机保存；不能混用“已发送”的成功标志。
4. 不可交互的介绍卡片不显示操作箭头。
5. B 站和小红书用文字名称，避免拿通用方框冒充平台标志。
6. SVG 在界面中为装饰语义，设置 `aria-hidden`；链接和按钮必须具有可见文字、输入标签或明确的可访问名称。
7. 图标名称由 TypeScript 校验，不允许拼错后悄悄显示默认箭头。
8. 交互仍沿用统一按钮圆角、留白、焦点描边和手机导航展开 / 关闭状态。

## 内部维护

- 设计说明只保留在仓库文档。公开网站不设置图标展示、设计教学或图标下载入口。
- 专属图标直接用于硬件分类和功能控件，不改动硬件介绍内容。
- `/icons/<name>.svg`：独立 SVG 文件，由同一份源数据静态生成。
- `public/favicon.svg`：品牌标记。
- `src/styles/icons.css`：本套图标和配套交互的样式。
